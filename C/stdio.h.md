
## Ввод и вывод на консоль

- `putchar()` – вывод символа через поток **stdout**;
- `printf()` – форматный вывод строки через поток **stdout**;
- `perror()` – вывод ошибок в виде строки через поток **stderr**;
- `getchar()` – чтение одного байта (символа) из потока **stdin**;
- `scanf()` – форматный ввод данных из потока **stdin**.

```cpp
#include <stdio.h>
```

### `getchar()`

```cpp
int getchar(void);
```

```cpp
#include <stdio.h>
 
int main(void)
{
    int value = getchar();
 
    return 0;
}
```

Функция `getchar()` предназначена для чтения **одного байта** из входного потока **stdin**. Помимо байтового диапазона [0; 255] целых чисел функция `getchar()` дополнительно может вернуть значения вне этого диапазона, в частности, `-1`.

Стандартный поток ввода **stdin** вполне можно связать с файлом и тогда данные будут читаться из него, а не с клавиатуры и при достижении конца файла будет сгенерировано значение `EOF`. И, во-вторых, при вводе с клавиатуры мы также можем симитировать достижение конца файла путем ввода специального символа комбинацией клавиш `Ctrl+Z` для ОС Windows и `Ctrl+D` для ОС Linux.

>Таким образом, функции `getchar()` нужно возвращать целые значения, превышающий байтовый диапазон [0; 255]. Поэтому разработчик языка Си решил использовать тип `int`

#### Чтение строк

```c
#include <stdio.h>
 
int main(void) 
{
	char bf[10];
	
	int max_len = sizeof(bf), i = 0;
	char *ptr = bf, ch;
	
	while((ch = getchar()) != '\n' && ch != EOF && i < max_len-1)
		   ptr[i++] = ch;
	
	ptr[i] = '\0';
	
	puts(bf);
		   
	return 0;
}
```

### `putchar()`

Служит для **вывода одного байта** (символа) в выходной поток `stdout` и определена следующим образом:

```c
int putchar(int ch);
```

В качестве аргумента принимает код символа в диапазоне [0;255]. Любое другое значение за пределами этого диапазона просто будет приводиться к восьми битам и затем помещаться в выходной поток `stdout`. Возвращает эта функция код символа, переданного в выходной поток:

```cpp
#include <stdio.h>
 
int main(void)
{
    int value = getchar();
    int res = putchar(value);
    printf("\n%d\n", res);
 
    return 0;
}
```

### `puts()`

Выводит нулём завершающуюся строку (`'\0'`) в поток `stdout` и автоматически добавляет символ новой строки `'\n'`

```c
char str[] = "Hello";
puts(str); // "Hello" и перевод на новую строку
```

### `printf()`

```c
int printf(const char* format, …);
```

Первый параметр **format** функции `printf()` определяет не просто выводимую строку, а формат выдаваемых данных. И для этого в нашем распоряжении имеются, так называемые, **спецификаторы преобразования**:

#### Спецификаторы преобразований `%`

Знак `%` указывает функции `printf`, как именно нужно интерпретировать байты. То есть это могут быть переменные, литералы или выражения.

```c
int x = 42; 

// 1. Переменная 
printf("%d\n", x); 

// 2. Литерал (константа) 
printf("%d\n", 42); 

// 3. Выражение (математическая операция или вызов функции) 
printf("%d\n", x + 100);
```

| **Спецификатор** | **Описание**                                                           |
| ---------------- | ---------------------------------------------------------------------- |
| %d или %i        | Целое число со знаком в десятичной форме.                              |
| %u               | Целое беззнаковое (unsigned) число в десятичной форме.                 |
| %o               | Целое беззнаковое (unsigned) число в восьмеричной форме.               |
| %x или %X        | Целое беззнаковое (unsigned) число в шестнадцатеричной форме.          |
| %f или %F        | Вещественное число в виде десятичной дроби. (**double** или **float**) |
| %e или %E        | Вещественное число в экспоненциальной форме.                           |
| %c               | Символ в соответствии с текущей кодовой таблицей.                      |
| %s               | Строка (последовательность символов).                                  |
| %%               | Запись символа % в форматной строке.                                   |
| %p               | Указатели (в формате 0x), 8 байт                                       |
| `%td`            | Вывод разницы двух указателей `ptrdiff_t`                              |
>Спецификаторы должны быть согласованы с типами данных переменных или выражений!

```c
#include <stdio.h>

int main(void) {
    int d = 1000;

    printf("%d\n", d); // 1000
    printf("%u\n", d); // 1000
    printf("%o\n", d); // 1750
    printf("%x %X\n", d, d);  // 3e8 3E8

    double f = 23.1234567; 
    printf("%f\n", f); // 23.123457
    printf("%f\n", d); // 0.000000 нельзя исп. спецификатор для вещ-х чисел с int!
    printf("%e\n", f); // 2.312346e+01

    char c = 70;
    printf("%c\n", c); // F
    
    char bf[12] = "hello world!";
    printf("string = %s", "hello");
    printf("%s", bf);
    
    return 0;
}
```

#### Суффиксы типов для спецификаторов

Целочисленные типы `char` и `short`, при передаче значений функции `printf()`, автоматически приводятся к типу `int`. Поэтому спецификатор `%d` охватывает все три типа: `char`, `short`, `int`. Если же переменная имеет тип `long` или `long long`, то перед спецификаторами допустимо прописывать малые буквы `l` и `ll` соответственно:

- `l` – суффикс для типов `long` или `unsigned long`;
- `ll` – суффикс для типов `long long` или `unsigned long long`.

```c
printf("value = %lld\n", -12345678901234LL);
printf("value = %llu\n", 12345678901234LL);
```

Если при выводе в спецификаторах убрать буквы ll, то значение будет отображено некорректно:

```c
printf("value = %d\n", -12345678901234LL); // -1942892530
```

Аналогично и с вещественными типами: `float` автоматически преобразовывается в `double`, поэтому спецификаторы `%f`, `%F`, `%e` и `%E` корректно обрабатывают оба из них. А вот для типа `long double` следует прописывать суффикс в виде заглавной буквы `L`:

- `L` – суффикс для типа `long double`.

```cpp
long double var_ld = 0.5;
printf("value = %Lf\n", var_ld);
```

#### Флаги спецификаторов

Каждый спецификатор может быть дополнительно снабжен, так называемыми, флагами, которые предоставляют возможность более тонкой настройки выводимой информации. Ниже в таблице приведены основные из них.

| **Флаг**         | **Описание**                                                                                  |
| ---------------- | --------------------------------------------------------------------------------------------- |
| Десятичное число | Задает минимальную ширину поля выводимой информации.                                          |
| Знак «-»         | Задает выравнивание по левому краю в пределах спецификатора.                                  |
| Знак «+»         | Задает отображение чисел со знаками «+» и «-».                                                |
| Цифра 0          | Заполнение нулями свободной области в пределах спецификатора.                                 |
| Пробел           | Задает отображение положительных чисел с пробелом в начале и со знаком «-» для отрицательных. |
| Символ «#»       | Задает отображение префикса числа (0x – для шестнадцатеричных; 0 – для восьмеричных).         |
```c
#include <stdio.h>

int main(void) {
    int var_i = -1283;
    double var_d = 54.34675;

    printf("[%10d]\n", var_i); // [     -1283]
    printf("[%10f]\n", var_d); // [ 54.346750]
    
    printf("[%-10d]\n", var_i); // [-1283     ]
    printf("[%-10f]\n", var_d); // [54.346750 ]
    
    printf("[%12.7d]\n", var_i); // [    -0001283]
    printf("[%12.2f]\n", var_d); // [       54.35]
    
    printf("[%#X]\n", var_i); // [0XFFFFFAFD]
    printf("[%+.2f]\n", var_d); // [+54.35]
    
    unsigned char h = 11, m = 8, s = 1;
    printf("%02d:%02d:%02d", h, m, s); // 11:08:01

    return 0;
}
```


### `sprintf()`

```c
int sprintf(char *buffer, const char *format, ...);
```

Выполняет форматирование данных и записывает результат в строку (массив `char`), а не в поток вывода. При успехе возвращает количество записанных символов, **не включая** завершающий нуль-символ `'\0'`. При ошибке — отрицательное число (например, при ошибке кодирования).

- **`buffer`** — указатель на массив символов, куда будет записан результат. Должен быть достаточно большим, чтобы вместить всю строку + завершающий `'\0'`.
- **`format`** — строка формата (та же, что и у `printf`): спецификаторы `%d`, `%f`, `%s` и т.д.
- **`...`** — переменное число аргументов, значения которых подставляются в строку формата.

```c
#include <stdio.h>

int main(void) {
    char res[50];

    int x = 123;
    double y = 3.1212;
    char str[] = "Item";

    char format[] = "[%s: %d, %f]";
    sprintf(res, format, str, x, y);

    puts(res); // [Item: 123, 3.121200]

    return 0;
}
```

>**Не проверяет размер буфера** — если данных больше, чем вмещает `buffer`, возникает **переполнение буфера** (неопределённое поведение, уязвимость).

>Небезопасна при использовании с пользовательским вводом в строке формата (уязвимость форматной строки).

#### Ограничение размера для строк

Чтобы указать максимальное количество байт (=символов при ASCII), которое будет скопировано из исходной строки, используется спецификатор `%.10s`,  где вместо 10 можно указать произвольное значение.

- Если строка длиннее 5 символов — будут выведены **только первые 5**.
- Если строка короче 5 символов — выведется **вся строка** (точность — это максимум, а не минимум).
- В `sprintf` результат всегда завершается `'\0'`, поэтому в буфер попадёт до 5 символов + нуль-терминатор.

```c
char buf[100];
int n = sprintf(buf, "%.5s", "Hello, world!");
// buf = "Hello"
// n = 5 (без учёта '\0')
```

Если строка короче:
```c
sprintf(buf, "%.5s", "Hi");
// buf = "Hi"
```

**Можно задавать точность через аргумент:**
```c
sprintf(buf, "%.*s", 5, str);  // аналог %.5s
```

### `scanf()`

Выполняет форматированное чтение данных из стандартного входного потока `stdin`

```c
int scanf(const char* format, …);
```

Здесь первый параметр `format` – это указатель на форматную строку. Последующее троеточие указывает на произвольное число дополнительных параметров, как правило, переменных. Функция возвращает целое значение типа `int`, равное числу прочитанных элементов из входного потока `stdin`.

>Функция выполняет считывает данных из буфера, пока они удовлетворяют форматной строке. При этом считывание останавливается либо после получения всех необходимых данных, либо при ошибке формата ввода. И следует помнить, что ошибочные данные остаются во входном буфере.

#### Спецификаторы преобразований

| **Спецификатор**             | **Описание**                                                                                              |
| ---------------------------- | --------------------------------------------------------------------------------------------------------- |
| %d                           | Целое число со знаком в десятичной форме. (Приводится к типу `int`).                                      |
| %i                           | Целое число в десятичной, шестнадцатеричной или восьмеричной системах. (Приводится к типу `int`).         |
| %u                           | Целое беззнаковое (`unsigned`) число в десятичной форме. (Приводится к типу unsigned `int`).              |
| %o                           | Целое число в восьмеричной форме. (Приводится к типу `int`).                                              |
| %x, %X                       | Целое число в шестнадцатеричной форме. (Приводится к типу `int`).                                         |
| %f, %e, %g<br><br>%F, %E, %G | Вещественное число. (Приводится к типу `float`).                                                          |
| %c                           | Символ в соответствии с текущей кодовой таблицей. (Приводится к типу `char`).                             |
| %s                           | Строка (последовательность символов). Читается до первого пробела, перевода строки или символа табуляции. |
```c
int res = scanf("%c%c", &byte1, &byte2);
printf("res = %d: byte1 = %c, byte2 = %c\n", res, byte1, byte2);
```

#### Чтение числовых значений

Если данные представлены в виде целых десятичных чисел со знаком, то для этого часто используют спецификатор `%d`. Причем, этот спецификатор приводит целые числа к типу `int`

```cpp
#include <stdio.h>
 
int main(void)
{
    long long var_lli = 0;
 
    int res = scanf("%d", &var_lli); // Сначала данные переводятся в int, а уже 
								     // потом сохранятся в переменную с типом 
								     // long long int
    printf("res = %d: var_lli = %lld\n", res, var_lli);
 
    return 0;
}
```

Если значение будет, например: *12345678901234*, то это значение сначала будет приведено к типу `int` и только затем записано в переменную *var_lli* типа `long long`. Поэтому на выходе увидим некорректное значение:

```c
res = 1: var_lli = 1942892530
```

Если нам нужно прочитать очень длинное целое число и сохранить его в типе `long long`, то следует в функции `scanf()` использовать модификатор `%lld`:

```cpp
int res = scanf("%lld", &var_lli);
```
#### Модификаторы

| **Модификатор**      | **Описание**                                                                                                 |
| -------------------- | ------------------------------------------------------------------------------------------------------------ |
| h                    | `%hd`, %hi – для **short int**;<br><br>`%hx`, %ho, %hu – для **unsigned short**                              |
| hh                   | `%hhd` – для **signed char**;<br><br>`%hhu` – для **unsigned char**                                          |
| l                    | `%ld`, %li – для long int;<br><br>%lx, %lo, %lu – для unsigned long;<br><br>`%lf`, %lg, %le – для **double** |
| L                    | %Lf, %Lg, %Le – для long double                                                                              |
| ll (в стандарте C99) | %lld – для long long int;<br><br>%llu – для unsigned long long                                               |
| цифры                | Максимальная ширина ввода (либо достигается максимальная ширина, либо служебный символ).                     |
| *                    | Пропуск данных.                                                                                              |
>Обратите внимание, спецификаторы `%f`, `%e`, `%g` выполняют преобразование данных к типу `float`, а не `double`, как это делает функция `printf()`. Если в функции `scanf()` используется переменная типа `double`, то для нее следует применять модификаторы `%lf`, `%le`, `%lg`. Например:

```cpp
#include <stdio.h>
 
int main(void)
{
    long long var_lli = 0;
    double var_d = 0;
 
    int res = scanf("%lld %lf", &var_lli, &var_d);
    printf("res = %d: var_lli = %lld, var_d = %.2f\n", res, var_lli, var_d);
 
    return 0;
}
```

##### Модификатор *

Интересной особенностью обладает модификатор *, который позволяет пропускать вводимые данные. Например, мы знаем, что на входе ожидаются данные в формате:

| **id**                | **price**   | **weight**         |
| --------------------- | ----------- | ------------------ |
| целое число без знака | целое число | вещественное число |

Нас интересуют только поля *price* и *weight*. Причем, будем полагать, что числа записаны через разделитель точка с запятой *«;»*. Это частый формат csv-файла. Так вот, для считывания только двух последних значений форматную строку в функции `scanf()` можно записать следующим образом:

```cpp
#include <stdio.h>
 
int main(void)
{
    unsigned int price = 0;
    double weight = 0.0;
 
    int res = scanf("%*llu; %u; %lf", &price, &weight);
    printf("res = %d: price = %d, weight = %.2f\n", res, price, weight);
 
    return 0;
}
```

Введем с клавиатуры данные: *10; 1000; 54.65*. На выходе получим строку:

```c
res = 2: price = 1000, weight = 54.65
```

###### `%*[^:]`

Это спецификатор формата для `scanf`/`sscanf`/`fscanf`, который читает **набор символов** и **отбрасывает** его (не сохраняет никуда). Используется для **разбор пара `ключ:значение`** без выделения буфера под ключ или пропуска ненужных символов.

```c
%  *  [  ^  :  ]
│  │  │  │  │  └── закрывающая скобка набора
│  │  │  │  └───── символ ':' (граница набора)
│  │  │  └──────── '^' — инверсия набора
│  │  └─────────── начало набора символов
│  └────────────── '*' — «прочитать и выбросить» (suppress assignment)
└───────────────── начало спецификатора
```

**Как читается**
- `[...]` — **scanset**: множество допустимых символов.
- `[^...]` — **инвертированный scanset**: всё, **кроме** перечисленных.
- `[^:]` — «любой символ, кроме `:`».
- `*` — прочитанное **не записывается** в переменную (подавление присваивания). Соответствующий аргумент в списке **не указывается**.

Итого `%*[^:]` означает: **«прочитать последовательность символов, отличных от `:`, и выбросить её»**.

```c
char str[100];
sscanf("Name: Mike", "%*[^:]: %15s", str);
puts(str); // Mike
```

Диапазоны через `-`:
```c
%[0-9]      // цифры
%[a-zA-Z]   // латиница
%[^0-9\n]   // всё, кроме цифр и перевода строки
```
#### Обработка пробельных символов

```c
int res = scanf("%c %c", &byte1, &byte2);
```

Этот пробел означает любые пробельные символы, которые могут присутствовать между двумя порциями данных. К пробельным относят символы: **пробела**, **перевода строки**, **табуляции** (и реже некоторые другие). Кроме того, этот символ может и вовсе отсутствовать.

То есть, форматная строка `"%c %c"` указывает сделать следующее: прочитать первый символ из входного буфера (любой символ), затем, пропустить все пробельные символы и прочитать следующий не пробельный.

#### Обработка маски ввода

```c
int res = scanf("%c,%c", &byte1, &byte2);
```

```c
int res = scanf("%c, %c", &byte1, &byte2);

/*
Тогда будет читаться первый символ, затем должна идти запятая, возможные пробельные символы, а затем, следующий непробельный символ. То есть, теперь возможны такие варианты ввода данных:

c,d; c, d; c,\nd, c,\td и т.п.
*/
```

#### Считывание строк (слов)

Спецификатор `%s` считывает строку до первого пробельного символа (пробел, а также символы табуляции и переноса строки). В конце функция `scanf()` дописывает ноль, чтобы строка была корректной с позиции языка Си.

>Как правило, используется всегда совместно с модификатором, задающим максимальную ширину ввода, чтобы избежать выход на пределы массива

```c
char bf[10];
scanf("%9s", bf);

// "hello world"
// bf = ['h', 'e', 'l', 'l', 'o', '\0']

// "hello_world"
// bf = ['h', 'e', 'l', 'l', 'o', '_', 'w', 'o', 'r', '\0']
```

### `sscanf()`

```c
int sscanf(const char* str, const char* format, ...);
```

`sscanf()` — это **`scanf()`, который читает не из потока, а из строки**. Разбирает строку `str`согласно формату `format` и записывает результаты в переменные. Возвращает число успешно считанных значений или `EOF`, если достигнут конец файла.

```c
#include <stdio.h>

int main(void) {
    const char* str = "42 3.14 hello";
    int x;
    double y;
    char word[20];

    int n = sscanf(str, "%d %lf %19s", &x, &y, word);
    printf("Прочитано полей: %d\n", n);
    printf("x=%d y=%.2f word=%s\n", x, y, word);

    return 0;
}
```

### stdin

На программном уровне все эти потоки организованы в виде буферов приема или передачи информации. То есть, данные сначала поступают в буфер, а затем, уже либо на устройство вывода, либо в переменные программы. Данные поступают в программу, например, с клавиатуры, не напрямую, а через буфер ввода. То же самое с выводом. Сначала данные из программы попадаю в буфер вывода и только потом, например, отображаются на мониторе или записываются в файл

#### `Ctrl + D`

`Ctrl+D` — это команда драйверу терминала немедленно **передать программе всё**, что сейчас лежит в буфере ввода

1. **Если в буфере БЫЛИ символы (например, `abc`):**
    - Драйвер отправляет эти символы программе.
    - Программа забирает эти байты через `getchar()`.
    - Так как прочитано больше 0 байт, для программы это **обычные данные** (никакого `EOF`).
        
2. **Если буфер БЫЛ ПУСТ (вы ничего не ввели или уже всё отправили предыдущим `Ctrl+D`):**
    - Драйвер отправляет программе **0 байт**.
    - Операционная система возвращает системному вызову чтения значение `0`.
    - Функция `getchar()`, получив результат в `0` байт, понимает: _«Данных больше нет и не будет»_ — и генерирует значение **`-1` (`EOF`)**.

#### `EOF`

**EOF** — это определенный в `<stdio.h>` макрос (со значением `-1`), который функции ввода вроде `getchar()` возвращают при достижении конца файла или закрытии потока данных, сигнализируя программе, что читать больше нечего.

>`EOF` представляет собой константу, в программном коде обычно используется именно имя (идентификатор) константы, а не число `-1`

Библиотека C взводит внутри структуры `stdin` флаг конца файла. Из-за этого любые последующие вызовы `getchar()` сразу возвращают `-1`, даже не пытаясь спросить данные у ОС.

Если вам снова нужно читать ввод с клавиатуры после того, как был получен `EOF` (например, от `Ctrl+D`), достаточно **сбросить этот флаг** с помощью функции **`clearerr(stdin)`**

```c
#include <stdio.h>

int main(void) {
    int c;

    while ((c = getchar()) != EOF) {
        putchar(c);
    }

    printf("\nПоймали EOF! Сбрасываем состояние stdin \n");

    clearerr(stdin); 

    while ((c = getchar()) != EOF) {
        putchar(c);
    }

    return 0;
}
```

#### Enter

С точки зрения драйвера терминала клавиша `Enter` делает **ровно то же самое, что и `Ctrl+D`**, но с двумя ключевыми отличиями:

1. **`Enter` добавляет символ переноса строки (`'\n'`):** Когда вы нажимаете `Enter`, драйвер терминала сначала записывает символ `'\n'` в свой внутренний буфер, а **затем сразу проталкивает** весь этот буфер в программу.
    
2. **В буфере гарантированно есть хотя бы 1 символ (`'\n'`):** Даже если вы нажмете `Enter` на абсолютно пустой строке, в буфер всё равно попадет `'\n'`. Именно поэтому `Enter` **никогда не вызывает `EOF`** — программа всегда считывает как минимум один байт (код `10`).

#### `Ctrl + C`

`Ctrl + C` — это команда драйверу терминала мгновенно отправить процессс-программе сигнал прерывания `SIGINT`(Signal Interrupt)

## Управляющие символы

![[image-35-1024x934.png]]

Это непечатные символы (с ASCII-кодами от `0` до `31`), которые предназначены не для отображения графических знаков, а для управления устройством вывода (терминалом, дисплеем или принтером).

| **Escape-последовательность** | **Название**             | **Название в ASCII**     | **ASCII-код** | **Что делает с курсором/выводом**                 |
| ----------------------------- | ------------------------ | ------------------------ | ------------- | ------------------------------------------------- |
| **`\n`**                      | Перевод строки           | **Line Feed (LF)**       | `10`(`0x0A`)  | Перещает курсор на новую строку вниз.             |
| **`\b`**                      | Возврат на шаг           | **Backspace (BS)**       | `8`(`0x08`)   | Сдвигает курсор на один символ влево (назад).     |
| **`\t`**                      | Горизонтальная табуляция | **Horizontal Tab (HT)**  | `9`(`0x09`)   | Сдвигает курсор к следующей позиции табуляции.    |
| **`\r`**                      | Возврат каретки          | **Carriage Return (CR)** | `13`(`0x0D`)  | Перемещает курсор в самое начало текущей строки.  |
| **`\0`**                      | Нуль-символ              | **Null Character (NUL)** | `0`(`0x00`)   | Маркер конца строки в Си (не выводится на экран). |
```c
#include <stdio.h>

int main() {
    char str[] = "Hello";

    for (int i = 0; str[i] != '\0'; i++) {
        putchar(str[i]);
        putchar('-');
    }
    printf("\b \n"); // H-e-l-l-o 
			         // То есть на последнем - выставляет каретку на его
			         // и затираем пробелом 
}
```
