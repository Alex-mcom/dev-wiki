## `argc` и `argv`

```c
int main(int argc, char *argv[])
```

Когда вы запускаете программу так:

```bash
./program -v -o result.txt file1.txt file2.txt
```

Операционная система передаёт в `main()` примерно следующее:

```text
argc = 5

argv[0]  →  "./program"          // имя программы (как её вызвали)
argv[1]  →  "-v"
argv[2]  →  "-o"
argv[3]  →  "result.txt"
argv[4]  →  "file1.txt"
argv[5]  →  "file2.txt"
argv[6]  →  NULL                 // всегда есть завершающий NULL
```

**Важные факты:**
- `argv[0]` — это **не** обязательно имя файла. Это то, как программу вызвали (`./program`, `/usr/bin/program`, `program` и т.д.).
- `argv[argc]` **всегда** равен `NULL`. Это стандарт.
- Все строки в `argv` — это обычные C-строки (`char*`), заканчивающиеся `\0`.
- Память под `argv` и все строки выделяет операционная система. Тебе **нельзя** их `free()`.


## `getopt()`

Функция для разбора коротких аргументов командной строки (опций вида `-a`, `-b value`, `-abc` и т.д.

```c
#include <unistd.h>   // getopt, optarg, optind, optopt, opterr

int getopt(int argc, char * const argv[], const char *optstring);
```

- `argc` — кол-во аргументов командной строки (приходит в `main()`)
- `argv` — массив указателей на аргументы командной строки (приходит в `main()`)
- `optstring` описывает, какие короткие опции допустимы.
- Если после буквы стоит `:`, то у опции **обязательный** аргумент.
- Если `::` — аргумент **необязательный**.

### [[Аргументы командной строки#Возвращаемые значения|Возвращаемые значения]]


```c
#include <stdio.h>
#include <unistd.h>

int main(int argc, char *argv[])
{
    int opt;
    int verbose = 0;
    char *output = NULL;

    // "vo:" означает:
    // -v        — флаг без аргумента
    // -o <file> — опция с обязательным аргументом
    while ((opt = getopt(argc, argv, "vo:")) != -1) {
        switch (opt) {
            case 'v':
                verbose = 1;
                break;
            case 'o':
                output = optarg;   // указатель на аргумент опции
                break;
            case '?':              // неизвестная опция или отсутствует аргумент
                // getopt уже вывел сообщение об ошибке (если opterr == 1)
                return 1;
            default:
                break;
        }
    }

    if (verbose)
        printf("Verbose mode on\n");
    if (output)
        printf("Output file: %s\n", output);

    // После цикла optind указывает на первый не-опционный аргумент
    for (int i = optind; i < argc; i++) {
        printf("Non-option argument: %s\n", argv[i]);
    }

    return 0;
}
```

**Запуск:**

```bash
./prog -v -o result.txt file1 file2
./prog -voresult.txt file1          # тоже работает (слитно)
./prog -v -o                      # ошибка: отсутствует аргумент у -o
```

**Важные глобальные переменные**

| Переменная | Описание                                                                                 |
| ---------- | ---------------------------------------------------------------------------------------- |
| `optarg`   | Указатель на аргумент текущей опции (или `NULL`)                                         |
| `optind`   | Индекс следующего необработанного аргумента в `argv`                                     |
| `optopt`   | Символ неизвестной/ошибочной опции                                                       |
| `opterr`   | Если 1 (по умолчанию) — getopt сам печатает ошибки в `stderr`. Поставь 0, чтобы подавить |

## `getopt_long()`

Расширение классического `getopt()`, которое позволяет разбирать **и короткие** (`-v`, `-o file`), **и длинные** (`--verbose`, `--output=file`) опции. Это стандарт GNU (есть почти везде в Linux, в т.ч. `musl`). В чистом POSIX его нет, только `getopt()`.

```c
#include <getopt.h>     // getopt_long, struct option

int getopt_long(int argc, char * const argv[],
                const char *optstring,
                const struct option *longopts,
                int *longindex);
```

- `argc` — кол-во аргументов командной строки (приходит в `main()`)
- `argv` — массив указателей на аргументы командной строки (приходит в `main()`)
- `optstring` — строка коротких опций (как в обычном `getopt()`).
- `longopts` — массив структур `struct option`, **обязательно** заканчивается нулевой записью `{0}`.
- `longindex` — указатель на переменную, в которую запишется индекс найденной длинной опции в массиве (можно передать `NULL`, если не нужно).


```c
static int parse_args(const int argc, char* argv[], opts_t* opts,
                      int* first_file_idx) {
  int opt;

  while ((opt = getopt_long(argc, argv, short_opts, long_opts, NULL)) != -1) {
    switch (opt) {
      case 'A':
        opts->show_nonprinting = true;
        opts->show_ends = true;
        opts->show_tabs = true;
        break;

      case 'b':
        opts->number_nonblank = true;
        opts->number_all = false;
        break;

      case 'e':
        opts->show_nonprinting = true;
        opts->show_ends = true;
        break;

      case '?':
        return -1;
    }
  }

  *first_file_idx = optind;

  return 0;
}
```
### Структура `struct option`

```c
/* Структура находится в getopt.h, её не нужно создавать самому */

struct option {
    const char *name;     // длинное имя без "--"  ("verbose")
    int         has_arg;  // тип аргумента
    int        *flag;     // куда писать значение (или NULL)
    int         val;      // значение, которое вернёт getopt_long()
};
```

**Возможные значения `has_arg`:**
- `no_argument` (0) — аргумента нет (`--verbose`)
- `required_argument` (1) — аргумент обязателен (`--output=file` или `--output file`)
- `optional_argument` (2) — аргумент необязателен (`--color` или `--color=auto`)

**Как работает `flag` и `val`:**

| flag      | Поведение                                                               |
| --------- | ----------------------------------------------------------------------- |
| `NULL`    | `getopt_long()` возвращает `val` (обычно короткая буква, например, `v`) |
| не `NULL` | записывает `val` в `*flag` и возвращает `0`                             |

Самый распространённый и удобный способ — ставить `flag = NULL` и возвращать короткую букву.

`getopt_long()` ожидает именно массив структур `option`, где каждая `struct option` описывает свой отдельный длинный флаг. При этом важно обязательно в конце добавить пустую структуру `{0}`, чтобы функция понимала, где конец этого массива.

```c
/* Структура, описывающая объект длинных флагов для getopt_long */

static const struct option long_opts[] = {
    {"number-nonblank", no_argument, NULL, 'b'},
    {"number", no_argument, NULL, 'n'},
    {"squeeze-blank", no_argument, NULL, 's'},
    {"show-ends", no_argument, NULL, 'E'},
    {"show-all", no_argument, NULL, 'A'},
    {"show-tabs", no_argument, NULL, 'T'},
    {"show-nonprinting", no_argument, NULL, 'v'},
    {0, 0, 0, 0}};
```

### Возвращаемые значения

Обе функции возвращают значение типа `int`. Возможные варианты:

>[!Успешный разбор опции]

| Что вернули                             | Когда это происходит                                                                                                              |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| **Символ опции** ('v', 'o', 'h' и т.д.) | Найдена короткая опция **или** длинная опция, у которой `flag == NULL`. В этом случае возвращается поле `val` из `struct option`. |
| **0**                                   | Найдена длинная опция, у которой `flag != NULL`. При этом значение `val` записывается в `*flag`, а функция возвращает `0`.        |

> [!Ошибки]

| Возвращаемое значение    | Причина                                                                                                                                                                       |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **'?'** (символ вопроса) | 1. Неизвестная опция  <br>2. У опции с `required_argument` отсутствует аргумент                                                                                               |
| **':'** (двоеточие)      | Только если в `optstring` **первым** символом стоит `:`.  <br>Тогда при отсутствии обязательного аргумента возвращается `:` вместо `?` (и сообщение об ошибке не печатается). |

> [!Конец опций]

| Возвращаемое значение | Значение                                                                                |
| --------------------- | --------------------------------------------------------------------------------------- |
| **-1**                | Опции закончились. Дальше в `argv` идут обычные аргументы (начиная с индекса `optind`). |


```c
int opt;

while ((opt = getopt_long(argc, argv, "vo:h", long_options, NULL)) != -1) {
    switch (opt) {
        case 'v':   // короткая или длинная --verbose
        case 'o':   // короткая или длинная --output
        case 'h':   // --help
            // ...
            break;

        case 0:     // сработала опция с flag != NULL
            // ...
            break;

        case '?':   // ошибка
            // ...
            return 1;

        case ':':   // отсутствует обязательный аргумент
                    // (только если optstring начинается с ':')
            // ...
            break;
    }
}

// Здесь opt == -1 — опции закончились
```
### Индекс первого непозиционного аргумента

Когда `getopt()` или `getopt_long()` успешно обработали все флаги, в глобальную переменную `optind` (объявлять самостоятельно не нужно, объявлена в заголовочных файлах `unistd.h` и `getopt.h`), заносится индекс первого непозиционного аргумента (то есть первого аргумента без `-` или `--`). Обычно это файлы 


```c
*first_file_idx = optind;
```
