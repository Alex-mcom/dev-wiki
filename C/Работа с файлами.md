# Открытие и закрытие файлов

## `fopen()`

```c
FILE *fopen(const char *filename, const char *mode);
```

Открывает файл для чтения и (или) записи. Возвращает указатель на `FILE` или `NULL` при ошибке.

| **Режим** | **Описание**                                                                                                                                                                  |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| "r"       | Открытие текстового файла только на чтение.                                                                                                                                   |
| "w"       | Открытие текстового файла только на запись. Если файл не существует, то он создается. Если существует, то все его прежнее содержимое удаляется.                               |
| "a"       | Открытие текстового файла на дозапись (новые данные добавляются в конец файла). Если файл не существует, то он создается.                                                     |
| "r+"      | Открытие текстового файла для чтения и записи одновременно. (новый файл не создается и прежнее содержимое не удаляется)                                                       |
| "w+"      | Открытие текстового файла для чтения и записи. Если файл не существует, то он создается. Если существовал, то все его прежнее содержимое удаляется.                           |
| "a+"      | Открытие текстового файла для чтения и записи. Добавлять данные можно только после имеющегося содержимого. Читать можно все данные. Если файл не существует, то он создается. |

Для бинарных режимов добавляют `b`: `"rb"`, `"wb"`, `"ab"`, `"r+b"` и т.д.

```c
FILE* f = fopen("data.txt", "w");
    if (f == NULL) {
        perror("fopen");
        return 1;
    }
```

## `fclose()`

```c
int fclose(FILE *stream);
```

Закрывает файл. Возвращает `0` при успехе, `EOF` — при ошибке. **Всегда закрывайте файлы** — иначе возможна потеря данных из буфера.

- Сбрасывает выходной буфер в файл.
- Освобождает ресурсы (память буфера, дескриптор).

```c
if (fclose(f) != 0) {
        perror("fclose");
        return 2;
    }
```

# Текстовый режим чтения

При открытии в режиме `"r"` (текстовый режим) поток `FILE*` переводится в **текстовый режим**. В этом режиме стандарт разрешает (а на многих системах — обязывает) выполнять **трансляцию** при чтении:

|Что делает реализация|Последствия|
|---|---|
|\r\n → \n|Два байта превращаются в один|
|Иногда одиночный \r тоже обрабатывается|Ещё сильнее меняется содержимое|
|На некоторых системах 0x1A (Ctrl+Z) считается концом файла|Чтение обрывается раньше реального EOF|

В текстовом режиме данные читаются **уже после** этой обработки.
# Ввод/вывод

## Посимвольный

### `fgetc()` 

```c
int fgetc(FILE *stream);
```

Чтение одного символа. Возвращает код символа (0–255) или `EOF` в конце файла/при ошибке.  

>**Важно:** возвращает `int`, а не `char` — чтобы отличить `EOF` (обычно `-1`) от символа `0xFF`.


### `fputc()`

```c
int fputc(int c, FILE *stream);
```

Запись одного символа. Возвращает записанный символ или `EOF` при ошибке.

## Строковый

### `fgets()` — чтение строки из потока

```c
char *fgets(char *str, int max_len, FILE *stream)
```

Читает из указанного входного потока **до `max_len - 1` символов** и сохраняет их в массив `str`, завершая результат нулевым символом `'\0'`. Чтение останавливается, когда будет встречен символ перевода строки `'\n'`, либо конец файла `EOF`, либо прочитано **max_len-1**. Все найденные символы `'\n'` будут добавлены в массив.

- **`NULL`** — при `EOF` (до чтения хоть одного символа) или ошибке

```c
#include <stdio.h>

int main(void) {
    char buff[10];
    FILE* fp = fopen("data.txt", "r");
    if (fp == NULL) { perror("fopen"); return 1; }

    while (fgets(buff, sizeof(buff), fp) != NULL) {
        printf("%s", buff);
    }

    fclose(fp);
    return 0;
}
```

```c
char buffer[10];
fgets(buffer, sizeof(buffer), stdin);

// при hello + Enter
// будет записано в buffer ['h', 'e', 'l', 'l', 'o', '\n', '\0']

// при hello + Ctrl + D (2 раза)
// будет записано в buffer ['h', 'e', 'l', 'l', 'o', '\0']

// при hello wor + Enter
// buffer = ['h', 'e', 'l', 'l', 'o', ' ', 'w', 'o', 'r', '\0']
```

### `getline()` и `getdelim()` построчное чтение в динамически расширяемый буфер

>Не входят в базовый стандарт ISO C (`C89/C99/C11`), требуют `POSIX.1-2008`

```c
#define _POSIX_C_SOURCE 200809L
#include <stdio.h>

ssize_t getline(char **restrict lineptr, size_t *restrict n, FILE *restrict stream);

ssize_t getdelim(char **restrict lineptr, size_t *restrict n, int delim, FILE *restrict stream);
```

**getline()** считывает целую строку, сохраняя адрес буфера, содержащего текст, в `*lineptr`. Буфер завершается `\0` и содержит символ новой строки, если был найден разделитель для новой строки.

Если `*lineptr` равно **NULL,** то **getline()** будет создавать буфер для содержимого строки, который затем должен быть высвобожден программой пользователя. Как альтернатива, перед вызовом **getline(),** `*lineptr` может содержать указатель на буфер, размещенный через **malloc()** с размером `*n` байтов. Если буфер недостаточно велик для размещения всей считанной строки, то **getline()** изменяет размер буфера с помощью **realloc(),** обновляя `*lineptr` и `*n` при необходимости. В любом случае при успешном вызове `*lineptr` и `*n` будут обновлены для отражения адреса буфера и его размера соответственно.

>**getdelim()** работает аналогично **getline(),** за исключением того, что разделитель строки, отличающийся от символа новой строки будет определен, как аргумент `delimiter`. Как и с **getline(),** символ-разделитель не добавляется, если на вводе не появилось знака разделения и уже достигнут конец файла.

**Параметры:**
- **`lineptr`** (`char **`) — адрес указателя на буфер.
	- Если `*lineptr == NULL` перед вызовом, `getline` выделяет начальный буфер через `malloc`
	- Если `*lineptr != NULL`, он должен указывать на память, выделенную `malloc`, размером `*n`байт. Буфер будет расширен через `realloc`, если не вмещает строку.

- **`n`** (`size_t *`) — адрес переменной, хранящей **текущий размер выделенного буфера** (не максимальную длину строки).
- **`stream`** (`FILE *`) — поток ввода. 
- **`delim`** (`int`, только для `getdelim`) — символ-разделитель, по которому прекращается чтение.

**Возвращаемые значения:**
- **При успехе**: `ssize_t` — количество прочитанных символов, **включая** разделитель, но **исключая** завершающий `'\0'`. Именно это значение (а не `strlen`) позволяет обнаружить **встроенные нулевые байты** в прочитанных данных, так как `strlen` остановится на первом же `'\0'

- **Ошибка или EOF**: `-1`.
	- **EOF**: выставляется индикатор конца файла в потоке (`feof(stream)` станет истинным).
	- **Ошибка**: выставляется индикатор ошибки потока (`ferror(stream)`), а `errno` устанавливается в причину

```c
#define _POSIX_C_SOURCE 200809L
#include <stdio.h>
#include <stdlib.h>
#include <errno.h>

int main(void) {
    FILE *fp = fopen("file.txt", "r");
    if (!fp) { perror("fopen"); return 1; }

    char *line = NULL;   // getline сама выделит память
    size_t cap = 0;      // начальная ёмкость
    ssize_t nread;

    while ((nread = getline(&line, &cap, fp)) != -1) {
        // nread — фактическое число байт (может включать '\0')
        // cap — текущая ёмкость буфера (может быть больше nread)
        printf("Прочитано %zd байт (ёмкость %zu)\n", nread, cap);
    }

    if (ferror(fp)) {
        perror("getline");
    }

    free(line); // ОБЯЗАТЕЛЬНО, даже если цикл завершился с ошибкой
    fclose(fp);
    return 0;
}
```

**Примечания**
1. Требует обязательного освобождения памяти, выделенной для буфера
2. Не позволяет задать максимальный размер при динамическом выделении памяти, если при очередном запросе на новую память система откажет, вернёт `-1` и установит `errno` в `ENOMEM`

### `fputs()` — запись строки в поток

```c
int fputs(const char* str, FILE* stream);
```

Записывает строку `str` в поток `stream`. Пишет все символы до `'\0'` (сам `'\0'` **не пишется**). `'\n'` **не добавляется автоматически**.

**Возвращаемое значение**
- **Неотрицательное число** — при успехе
- **`EOF`** — при ошибке

```c
FILE* fp = fopen("out.txt", "w");
if (fp == NULL) { perror("fopen"); return 1; }

fputs("Hello, ", fp);
fputs("world!\n", fp);  // \n нужно добавлять вручную

fclose(fp);
```

## Форматный

### `fprintf()` — форматированная запись в поток

```c
int fprintf(FILE* stream, const char* format, ...);
```

Работает как `printf()`, но выводит в **указанный поток** (файл, `stderr` и т.д.).

**Возвращаемое значение**
- **Число записанных символов** — при успехе
- **Отрицательное число** — при ошибке

```c
FILE* fp = fopen("log.txt", "w");
if (fp == NULL) { perror("fopen"); return 1; }

int x = 42;
double pi = 3.14159;
fprintf(fp, "x = %d, pi = %.2f\n", x, pi);
fprintf(stderr, "Ошибка: код %d\n", 5);

fclose(fp);
```

### `fscanf()` — форматированное чтение из потока

```c
int fscanf(FILE* stream, const char* format, ...);
```

Работает как `scanf()`, но читает из **указанного потока**.

**Возвращаемое значение**
- **Число успешно прочитанных и присвоенных полей**
- **`EOF`** — если конец файла достигнут до первого присваивания
- **Меньше ожидаемого** — если ввод не соответствует формату

```c
FILE* fp = fopen("data.txt", "r");
if (fp == NULL) { perror("fopen"); return 1; }

int x;
double y;
char name[50];

while (fscanf(fp, "%d %lf %49s", &x, &y, name) == 3) {
    printf("x=%d y=%.2f name=%s\n", x, y, name);
}

fclose(fp);
```

## Бинарный (блочный)

### `fread()` — бинарное чтение с буферизацией

```c
size_t fread(void *ptr, size_t size, size_t nmemb, FILE *stream);
```

Считывает максимум `nmemb` элементов размером `size` байт из входного потока `stream` и сохраняет их в буфер по указателю `ptr`

| Параметр | Тип    | Описание                                                                                                        |
| -------- | ------ | --------------------------------------------------------------------------------------------------------------- |
| `ptr`    | void * | Указатель на буфер, куда будут записаны прочитанные данные. Должен быть достаточно большим (size * nmemb байт). |
| `size`   | size_t | Размер **одного** элемента в байтах.                                                                            |
| `nmemb`  | size_t | Количество элементов, которые нужно прочитать.                                                                  |
| `stream` | FILE * | Открытый поток (обычно полученный через fopen в режиме "rb" / "r+b" и т.п.).                                    |
**Возвращаемое значение**
- Возвращает **количество успешно прочитанных элементов** (не байт!).
- При успешном полном чтении возвращает `nmemb`.
- При достижении конца файла или ошибке возвращает значение **меньше** `nmemb` (в том числе 0).

```c
int process_file(const char* f, opts_t* opts, state_t* state) {
  FILE* fp = fopen(f, "r");

  if (fp == NULL) {
    perror(f);
    return 1;
  }

  unsigned char buf[block_buff_size];
  size_t n;

  while ((n = fread(buf, 1, block_buff_size, fp)) > 0) {
    /* 
    Обработка полученных данных
    process_block(buf, n, opts, state);
    */
  }

  fclose(fp);
  return 0;
}
```

**Примечания**
- `fread` буферизована — чтение крупными блоками (`size * nmemb` в десятки-сотни килобайт) значительно эффективнее множества мелких вызовов. `read` (POSIX) — небуферизованный системный вызов;

# Позиционирование в файле

## `fseek()` — установка позиции в файле

```c
int fseek(FILE* stream, long offset, int whence);
```

Перемещает **индикатор позиции** в файловом потоке на новое место. Следующая операция чтения/записи начнётся с этой позиции.

| Параметр | Значение                             |
| -------- | ------------------------------------ |
| `stream` | Указатель на открытый файловый поток |
| `offset` | Смещение в байтах                    |
| `whence` | Точка отсчёта                        |
**Константы для `whence` (из `<stdio.h>`)**
- `SEEK_SET`: начало файла
- `SEEK_CUR`: текущая позиция
- `SEEK_END`: конец файла

- Для **текстовых потоков** `offset` должен быть либо `0`, либо значением, полученным от `ftell()` (и тогда `whence` — только `SEEK_SET`)
- Успешный вызов **сбрасывает** индикатор конца файла (`EOF`) и отменяет эффект `ungetc()`
- Для **режима добавления (`"a"`)** запись всё равно происходит в конец, даже если сдвинуть указатель

```c
// Перейти на 10 байт от начала
if (fseek(fp, 10, SEEK_SET) != 0) {
    perror("fseek");
}
```

## `ftell()` — узнать текущую позицию

```c
long ftell(FILE* stream);
```

Возвращает **текущую позицию индикатора** в потоке относительно начала файла

- **`long`** — текущая позиция (смещение от начала) при успехе
- **`-1L`** — ошибка (при этом `errno` устанавливается в `EBADF` или `EINVAL`

```c
fseek(fp, 0, SEEK_END);   // перейти в конец
long size = ftell(fp);    // узнать позицию (размер файла)
fseek(fp, 0, SEEK_SET);   // вернуться в начало
```

>Будет некорректно показывать позицию в **stdin**

# Проверка состояния и ошибок

## `perror()` — вывод сообщения об ошибке

```c
void perror(const char* s);  // требует <stdio.h> или <stdlib.h>
```

Выводит в **стандартный поток ошибок (`stderr`)** понятное текстовое описание ошибки, которая произошла в последнем системном или библиотечном вызове.

1. Берёт целочисленный код ошибки из глобальной переменной **`errno`** (определена в `<errno.h>`).
2. По этому коду находит системное сообщение (например, «No such file or directory»).
3. Выводит в формате: `<ваше_сообщение>: <системное_сообщение>\n`

```c
#include <stdio.h>

int main(void) {
    FILE* f = fopen("nosuchfile.txt", "r");
    if (f == NULL) {
        perror("fopen");  // Выведет: fopen: No such file or directory
        return 1;
    }
    fclose(f);
    return 0;
}
```

## `feof()` — проверка достижения конца файла

```c
int feof(FILE *stream);
```

Возвращает ненулевое значение, если при последней операции чтения был достигнут конец файла (`EOF`), иначе — 0.

**Важный нюанс:** флаг EOF выставляется **после** неудачной попытки чтения за концом файла, а не до неё. Поэтому классическая ошибка — проверять `feof()` перед чтением. 

> **Правильный паттерн использования**: Сначала вызывайте функцию чтения и **проверяйте её возвращаемое значение**, и только затем используйте `feof()`, чтобы отличить конец файла от ошибки

```c
while (fread(buf, 1, sizeof buf, fp) > 0) { /* ... */ }

if (feof(fp))        puts("Достигнут конец файла");
else if (ferror(fp)) perror("Ошибка чтения");
```

>Для текстового ввода (`fgets`, `fscanf`, `fgetc`) **`feof` не стоит использовать вообще**. `feof` реально полезна в **бинарном** вводе через `fread`, где результат чтения — это число байт, а не «успех/провал», и где EOF может прийти «посередине» законного чтения.


# Управление буфером

## `fflush()` — принудительный сброс буфера

```c
int fflush(FILE *stream);
```

Для **выходного** потока записывает всё содержимое буфера **библиотеки C** и передаёт их в **буфер ядра ОС** через системный вызов. Возвращает 0 при успехе, `EOF` при ошибке.

Гарантирует, что после успешного `fflush()` данные точно покинули пределы вашего процесса и оказались в кэше ОС. Другой процесс, читающий этот файл, **увидит изменения** сразу же. Но `fflush()` **не командует** операционной системе немедленно записать эти данные на физический диск. Они могут спокойно лежать в кэше ОС ещё несколько секунд. Если в этот момент пропадёт питание или система упадёт, данные пропадут. Для гарантии физической записи на диск, нужно после `fflush()` вызывать `fsync()`

>**Нестандартное, но повсеместно поддерживаемое поведение:** `fflush(stdin)` для сброса входного буфера. По стандарту C это **неопределённое поведение** (стандарт разрешает `fflush`только для выходных потоков и `NULL`), хотя MSVC и некоторые другие реализации это допускают

- `fflush(NULL)` сбрасывает **все** открытые выходные потоки.

## `fsync()` — приказ ОС физически записать данные


`fsync(fd)` работает с файловым дескриптором (`fd`) и приказывает **ядру ОС** сбросить все изменённые данные для этого файла из кэша на **физический носитель**

`fsync()` **блокируется** и ждёт, пока устройство подтвердит, что данные записаны на диск. Только после этого функция возвращает управление. Это даёт максимально возможную гарантию сохранности данных при внезапном сбое питания

Цепочка выглядит так:  
`Буфер программы (FILE*)` - `fflush()`-> `Буфер ядра (Page Cache)` - `fsync()`-> `Физический диск`

```c
#include <stdio.h>
#include <unistd.h>

// ... запись данных в fp ...

if (fflush(fp) != 0) {
    // ошибка сброса буфера библиотеки
}

// Получаем файловый дескриптор из FILE* и синхронизируем с диском
if (fsync(fileno(fp)) != 0) {
    // ошибка синхронизации с диском
}
```

## `setvbuf()` — настройка буферизации потока

```c
int setvbuf(FILE *stream, char *buf, int mode, size_t size);
```

Эта функция позволяет изменить режим буферизации и/или размер буфера для открытого потока. Её можно вызывать **только сразу после открытия потока и до любой другой операции ввода-вывода**

**`mode`** определяет тип буферизации (константы из `<stdio.h>`):
- `_IOFBF` – полная буферизация (очистка после заполнения буфера);
- `_IOLBF` – построчная буферизация (очистка по символу переноса строки);
- `_IONBF` – выключение буферизации

- **`buf`**: Указатель на ваш буфер. Если `NULL`, библиотека сама выделит буфер нужного размера (`size`)
- **`size`**: Размер буфера.

**Возвращает**: `0` при успехе, ненулевое значение при ошибке

```c
// Отключаем буферизацию — полезно для отладки/логов
setvbuf(fp, NULL, _IONBF, 0);

// Свой буфер: память должна жить, пока поток открыт
static char mybuf[8192];
setvbuf(fp, mybuf, _IOFBF, sizeof mybuf);

// Если buf == NULL, библиотека сама выделит буфер заданного размера
setvbuf(fp, NULL, _IOFBF, 65536);
```
