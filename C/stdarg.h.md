## Вариадические функции

Это функции с произвольным числом аргументов.

- `va_start()` – для получения указателя на первый вариадический параметр функции (тот, что идет после параметра count в нашем примере);
- `va_arg()` – для получения значения текущего параметра и переход к следующему вариадическому параметру;
- `va_end()` – для завершения процедуры перебора (это необходимо, если потребуется новый обход параметров, тогда нужно будет снова вызвать `va_start()` и `va_arg()` для извлечения значений).

```c
#include <stdio.h>
#include <stdarg.h>
 
int sum(int count, ...)
{
	int s = 0;
	va_list arg;            // указатель на параметр
	va_start(arg, count);   // получение адреса первого вариадического параметра 
	
	for(int i=0; i < count; ++i) {
				s += va_arg(arg, int);  // получение значение вариадического параметра
										// и переход к следующему параметру
	}
	
	va_end(arg);               // завершение процедуры перебора вариадических параметров
	
	return s;
}
 
 
int main(void) 
{
	int res = sum(5, 1, 2, 3, 4, 5);
	printf("res = %d\n", res);
	
	return 0;
}
```

### `va_list`

`va_list` это непрозрачный тип, «курсор» по аргументам. Его внутреннее устройство зависит от платформы (на x86-64 Linux это массив из одной структуры), поэтому нельзя ни разбирать его, ни копировать присваиванием `ap2 = ap1`. Работать с ним можно только через макросы.

```c
va_list ap;
va_start(ap, last_named);   // 1. инициализация
x = va_arg(ap, int);        // 2. сколько угодно раз
va_end(ap);                 // 3. обязательно закрыть
```

- `va_start` и `va_end` вызываются **в одной и той же функции**, парно.
- Двигаться можно только вперёд. Вернуться назад или прочитать аргумент по номеру нельзя. Для второго прохода нужен `va_copy`.
- Тип в `va_arg` должен точно соответствовать переданному. Иначе UB.
- Работает default promotion: для `%c`, `%hd`, `%hhd` читай `int`, для `%f` читай `double`, потом приводи к нужному типу.


#### Передача в другие функции

Это самое частое место, где ошибаются. Есть два варианта.

**1. По указателю `va_list *`.** Курсор продвигается и у вызывающего. Это то, что нужно для разбора формата по частям:

```c
static void print_int(va_list *ap, char *buf) {
    int v = va_arg(*ap, int);   // *ap, не ap
    ...
}
// вызов: print_int(&ap, buf);
```


**2. По значению `va_list ap`.** Так устроены `vsprintf`, `vprintf`. После возврата из такой функции значение `ap` у вызывающего **неопределено**, можно только вызвать `va_end`. Если после вызова нужно продолжать читать, передавай копию:

```c
va_list copy;
va_copy(copy, ap);
vfunc(format, copy);
va_end(copy);       // для каждой копии свой va_end
```


### `va_arg`

**Соответствие спецификаторов и типов в** `va_arg`

|Спецификатор|`va_arg(ap, ...)`|
|---|---|
|`%d`, `%i`, `%c`, `%hd`|`int` (дальше приведение к `short`/`char`)|
|`%u`, `%x`, `%o`, `%hu`|`unsigned int` (`%hu`: читаешь `unsigned`, приводишь к `unsigned short`)|
|`%ld`, `%lu`|`long`, `unsigned long`|
|`%f`, `%e`, `%g`|`double`|
|`%Lf`|`long double`|
|`%s`|`char *`|
|`%p`|`void *`|
|`*` в ширине/точности|`int`|
