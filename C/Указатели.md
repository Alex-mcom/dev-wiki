**Адресом переменной** называют порядковый номер ячейки, начиная с которой переменная хранится в памяти

**Указатели** - целочисленные переменные, хранящие адреса других переменных. Размер данных указателя в памяти определяется разрядностью системы. Если система *32-х* разрядная, то указатели занимают **4 байта**; если *64-х* разрядная, то **8 байт**:

![[Pasted image 20260910170613.png]]

```c
char d = 10;
char *gpt;       // объявили указатель gpt
gpt = &d;        // поместили в него адрес переменной d

char x = *gpt;   // считывание значения из ячейки памяти
*gpt = 100;      // запись значения 100 в ячейку памяти (разымёнывание)
```

```c
#include <stdio.h>
 
int main(void) 
{
	char d = 10;
	char *gpt;
	gpt = &d;
	
	printf("gpt = %p, *gpt = %d, d = %d\n", gpt, *gpt, d);
	// gpt = 0062ff1b, *gpt = 10, d = 10
	
	*gpt = 100;
	printf("gpt = %p, *gpt = %d, d = %d\n", gpt, *gpt, d);
	// gpt = 0062ff1b, *gpt = 100, d = 100
	
	return 0;
}
```

**Инициализация указателя** - при инициализации указателя ему присваивается адрес, а звездочка записана для объявления переменной *gpt* как указателя, а не просто как обычной переменной

```c
char *gpt = &d;
```

### Тип указателя

При объявлении указателя мы обязаны указывать его тип. Сам по себе указатель всегда хранит лишь адрес переменной и имеет фиксированный размер (4 байта / 8 байт). Тип, который мы указываем вначале, относится не к указателю, а к типу данных, с которыми его предполагается использовать.

```c
short var_short = 7; 
short *ptr_short = &var_short; // указатель на переменную типа short

int var_int = 65536; 
int *ptr_int = &var_int; // указатель на переменную типа int
```

Указывать тип указателя нужно по двум причинам:

**Чтобы знать, СКОЛЬКО БАЙТ читать при разыменовании (`*ptr_var`):**
Память процессора — это байтовый массив. Адрес в указателе говорит только о том, **где начинается** переменная, но не о том, где она заканчивается. 

```c
short var = 7;
short *ptr_var = &var;

short x = *ptr_var; // Разыменование
```

Благодаря типу `short*` компилятор понимает:

1. Нужно пойти по 8-байтовому адресу из `ptr_var`.
2. Считать оттуда **ровно 2 байта** (размер `short`).
3. Интерпретировать эти 2 байта как целое число со знаком.

Если бы тип был `int*`, компилятор попытался бы прочитать **4 байта**, захватив соседний мусор из памяти. Если бы тип был `double*` — он прочитал бы **8 байт** и попытался разобрать их как число с плавающей точкой.

**Чтобы корректно работала АРИФМЕТИКА УКАЗАТЕЛЕЙ (`ptr++`):**
Прибавка единицы к указателю (`ptr + 1`) в языке C означает **«перейди к следующему элементу в памяти»**, а не «прибавь 1 к адресу».

На сколько именно байт нужно сдвинуть адрес при `ptr++`, зависит от типа данных:

- Если `ptr` имеет тип **`char*`** (`sizeof(char) = 1`), то `ptr + 1` сдвинет адрес на **1 байт**.
- Если `ptr_var` имеет тип **`short*`** (`sizeof(short) = 2`), то `ptr_var + 1` сдвинет адрес на **2 байта**.
- Если `ptr` имеет тип **`int*`** (`sizeof(int) = 4`), то `ptr + 1` сдвинет адрес на **4 байта**.

```c
short arr[2] = {10, 20};
short *ptr = &arr[0]; // Пусть адрес равен 0x1000

ptr++; // Новый адрес станет 0x1002 (0x1000 + sizeof(short)), 
       // то есть указатель идеально встанет на начало arr[1]
```

## Универсальный тип `void *`

Указатель типа **`void *`** (называемый «универсальным» или «обобщенным» указателем) — это специальный тип указателя в C, который может хранить адрес объекта **любого типа данных**.

На 64-битной системе `void *` занимает те же **8 байт**, что и `int *` или `char *`, и хранит обычный адрес ячейки памяти. Однако для компилятора тип `void` означает: _«По этому адресу что-то лежит, но я не знаю, какого оно размера и как его интерпретировать»_.

**Автоматическое приведение типов (в C):** Указатель любого типа (`int *`, `char *`, `struct MyStruct *`) можно присвоить переменной `void *` **без явного приведения типов**. И наоборот: `void *` можно присвоить указателю любого конкретного типа.

```c
int x = 100;
void *ptr = &x;     // Легально: int* автоматически приводится к void*
int *p_int = ptr;   // Легально в C: void* автоматически приводится к int*
```
    
**Запрет на разыменование (`*ptr`):** Нельзя прочитать или записать значение напрямую через `void *`, так как компилятор не знает, сколько байт считывать (1, 2, 4 или 8).

**Запрет на арифметику указателей (`ptr + 1`)**


Указатели типа `void` используются для:

**Динамическое выделение памяти (`malloc`)**
Функция `malloc` выделяет запрошенное число байт в куче (Heap), но не знает, для чего вы используете эту память — для `int`, `double` или вашей структуры. Поэтому она возвращает `void *`:

```c
// malloc возвращает void*, который автоматически превращается в double*
double *arr = malloc(10 * sizeof(double));
```

## Приведение типов

**Приведение типов указателей** — это явное переопределение того, **как компилятор должен интерпретировать данные**, лежащие по конкретному адресу памяти.

Обычный `int` занимает 4 байта. Чтобы прочитать его «сырые» байты по отдельности, мы приводим `int *` к `char *`(так как `char` занимает ровно 1 байт):

```c
#include <stdio.h>

int main(void) {
    int n = 75432;
    unsigned char* ptr_byte = (unsigned char*)&n;

    for (int i = 0; i < sizeof(n); i++) {
        printf("%p: %d\n", ptr_byte + i, ptr_byte[i]);
    }

    return 0;
}
```

```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    size_t size = 3;
    // эквивалентно (int*)malloc(sizeof(int) * size)
    int* data = malloc(sizeof(int) * size);

    *data = 8; // data[0] = 8
    *(data + 1) = 19; // data[1] = 19
    data[2] = 3;

    for (int i = 0; i < size; i++) {
        printf("%d\n", data[i]);
    }

    return 0;
}
```

## Константа `NULL`

Специальный макрос, который обозначает **«нулевой указатель»**. Он указывает на то, что указатель в данный момент **никуда не ссылается** и не содержит валидного адреса памяти. Определён с помощью директивы `define` в заголовочном файле `stdio.h`

```c
#include <stdio.h>
 
int main(void) 
{
	int arg = 5;
	int *ptr = NULL;
	
	if(ptr != NULL)
	   *ptr = 1;
	
	return 0;
}
```

## Адресная арифметика

Когда мы работаем с указателями, а не с обычными переменными, то целочисленные **арифметические операции выполняются в соответствии с правилами адресной арифметики**. В частности, увеличение на единицу означает, что нам нужно перейти к следующей порции данных в памяти компьютера, а не к следующей ячейке. Именно поэтому адрес указателя увеличивается на размер типа данных, для которого он объявлен. 

### Смещение указателей

```c
#include <stdio.h>
 
int main(void) 
{
	int g = 4;
	int *ptr = &g;
	
	printf("ptr = %u\n", ptr); // ptr = 6487832
	
	ptr++;
	printf("ptr = %u\n", ptr); // ptr = 6487836 (+ 4 так как int)
	
	return 0;
}
```

В нашем примере – это тип `int`, который занимает *4 байта*. Поэтому увеличивая на единицу значение адреса указателя *ptr*, мы получаем прибавку на эти четыре байта. 

>Операции **должны быть** именно **целочисленными**. В них должны фигурировать или целочисленные литералы или целочисленные переменные. Другие типы здесь использовать недопустимо. Также нельзя использовать операции умножения и деления!

### Разность указателей

Возвращает расстояние в памяти между двумя элементами одного массива, причем расстояние выражено не в байтах, а в **кол-ве элементов** указанного типа.

Используется **только** между **двумя указателями** (целочисленные типы недопустимы). Причем эта операция имеет смысл исключительно с элементами одного массива

```c
short m[10];

printf("Адрес m[0]: %u\n", &m[0]);
printf("Адрес m[3]: %u\n", &m[3]);
printf("%td", &m[3] - &m[0]);
```

```
Адрес m[0]: 1861447060
Адрес m[3]: 1861447066
3 // 3, а не 6, так как тип short занимает 2 байта 
```

## `const` с указателями

> [!Указатель на константу (const int *ptr)]

>Константным является **то, на что указывает указатель** (данные).

**Данные**: Изменить нельзя (*`ptr = 20;` → ошибка*).
**Указатель**: Можно перенаправить на другой адрес (`ptr = &b;` → успешно).

Применяется в параметрах функций, чтобы случайно не изменить передаваемые данные (например, `void print_str(const char *str)`).

```c
short ar[5] = {0};
const short* ptr = ar;
// эквивалентная запись: short const *ptr = ar;

short x = ptr[1];
// ptr[1] = 1; // не можем менять значения через указатель

ptr = &x; // но можем менять адрес, на который ссылается указатель
printf("%d", *ptr);
```

----

> [! Константный указатель (`int *const ptr`)]
> 

>Константным является сам указатель (адрес).

**Данные:** Можно изменять (*`ptr = 20;` → успешно*).
**Указатель:** Нельзя перенаправить на другой адрес (`ptr = &b;` → **ошибка**).

```c
short ar[5] = {0};
short* const ptr = ar;

ptr[1] = 1; // можем менять значения через указатель

short x = 10;
// ptr = &x; // но не можем менять адрес, на который ссылается указатель
```

---

> [!Константный указатель на константу (`const int *const ptr`)]

>Запрещено изменять **и адрес, и данные**

```c
int a = 10;
int b = 20;

const int *const ptr = &a;

*ptr = 15; // ОШИБКА
ptr = &b;  // ОШИБКА
```

## `const` с переменными

>Запрещает менять значения переменной после её инициализации. При этом на уровне машинных кодов переменная остаётся переменной (не путать с тем, как работает директива `#define`), а это значит, что такое константные переменные мы также не можем использовать при указании размера массивов или в операторе `switch`

```c
/* Неправильное использования оператора switch */

const int code = 13;
int item = 1;

switch(item) {
case code:
	printf("error");
}
```

```
const int var;
```

Имеет смысл объявлять только в глобальной области видимости, в таком случае они автоматически инициализируются нулями. Внутри функций такие переменные будут всегда содержать только мусорные значения

## Указатели на функцию

**Указатели на функции** — это переменные, которые хранят адрес функции в памяти. Позволяют вызывать функции динамически, передавать их как аргументы и создавать таблицы функций.

`возвращаемый_тип (*имя)(типы_параметров)`

```c
int (*ptr)(int, int);  // указатель на функцию, принимающую два int и возвращающую int
```

**Не путать** 
```c
int *pred(int);   // функция, возвращающая int*
int (*pred)(int); // указатель на функцию, возвращающую int
```

```c
#include <stdio.h>

int sum(int a, int b) { return a + b; }

int main(void) {
    int (*ptr_func)(int, int);
    ptr_func = sum;

    int res = ptr_func(1, 2); // res = 3

    return 0;
}
```
### Передача в функцию (`callback`)

```c
#include <stdio.h>

#define SIZE 10

int is_positive(int n) { return n > 0; }

void filter(int dest[], size_t dest_sz, const int source[], size_t source_sz,
            int (*is_positive)(int)) {
    for (int i = 0, j = 0; i < source_sz && j < dest_sz; i++) {
        if (is_positive(source[i])) {
            dest[j++] = source[i];
        }
    }
}

int main(void) {
    int digits[] = {-3, 4, 10, 11, -5, 3};
    int dest[SIZE] = {0};

	// is_positive уже является указателем на функцию
    filter(dest, SIZE, digits, sizeof(digits) / sizeof(*digits), is_positive);

    return 0;
}
```

### Массив указателей на функции

**Массив указателей на функции** — это обычный массив, элементами которого являются указатели на функции. Обычно все функции в таком массиве имеют **одинаковую сигнатуру**(одинаковые типы параметров и возвращаемого значения). Это позволяет выбирать функцию по индексу во время выполнения программы.

Главная идея — **табличное программирование**. Вместо длинных `if/else` или `switch` вы строите таблицу функций и выбираете нужную по индексу или ключу. Это делает код компактнее, быстрее и легче расширяемым.

`тип_возврата (*имя_массива[размер])(типы_параметров)`

Пример для функций `int f(int, int)`:
```c
int (*ops[3])(int, int);

// Здесь `ops` — массив из 3 указателей на функции, принимающие два `int` и возвращающие `int`.
```

**Пример: меню команд**
```c
#include <stdio.h>

void cmd_help(void) { puts("Help: ..."); }
void cmd_run(void)  { puts("Running..."); }
void cmd_exit(void) { puts("Bye!"); }

int main(void) {
    void (*commands[])(void) = { cmd_help, cmd_run, cmd_exit };
    int choice = 1;  // например, выбрали "run"
    commands[choice]();  // вызовет cmd_run
    return 0;
}
```

## Примечания

==1.==
```c
for(int i = 0;i < sizeof(g); ++i)
	printf("%d ", *ptr++);
```

`*ptr++` работает тут как `*(ptr++)`: вначале мы получаем текущее значение `ptr`, к нему применяется операция `*` и только после этого адрес увеличивается на единицу.

==2==
```c
int g = 476789;
int *p = &g;
 
*p += 1;
```

Так как операция `*` является унарной, то она обладает большим приоритетом, чем операция `+=.` Поэтому здесь сначала будет прочитано значение переменной *g*, затем, оно увеличивается на единицу и результат снова заносится в те же ячейки памяти, где расположена переменная *g*. В итоге, значение указателя *p* не изменится, а переменная *g* станет на единицу больше.
