**grep** (от англ. _Global Regular Expression Print_) — это консольная утилита в Unix/Linux, которая ищет в тексте строки, соответствующие заданному шаблону, и выводит их.

**grep** выводит **целиком** совпавшую строку, то есть если в строке совпала только часть, выведется вся строка всё равно:

```file1.txt
apple
Apple
applepen other text
banana brain
app
```

```bash
cat file.txt | grep "apple"

apple
applepen other text
```

Ищёт именно совпадения **подстроки**, а не совпадение всего слова:
```bash
cat tests/data/file1.txt | grep "ap"

apple
applepen other text
app and other text
```

## Ключевые принципы `grep`:

1. **Построчная обработка**: `grep` читает входные данные (файл или стандартный ввод) **строка за строкой**. Он не анализирует весь текст целиком, а проверяет каждую строку на соответствие шаблону.
    
2. **Поиск по подстроке**: По умолчанию `grep` ищет шаблон **как подстроку** внутри строки. Это значит, что шаблон `кот` будет найден и в строке `кот`, и в `который`, и в `котлета`. Если вам нужно найти слово целиком, используйте флаг `-w` (целое слово) или `-x` (вся строка целиком).
    
3. **Регулярные выражения (Regex)**: `grep` использует регулярные выражения для описания шаблонов поиска. По умолчанию он работает с **базовыми регулярными выражениями (BRE)**, но с флагом `-E` переключается на более мощные **расширенные (ERE)**. Простые шаблоны (обычный текст) также являются регулярными выражениями, которые соответствуют сами себе.

## Флаги

### `-e` (Шаблон)

Позволяет явно указать шаблон для поиска. Это особенно полезно в двух случаях:

- Когда нужно задать **несколько шаблонов** для поиска.
- Когда шаблон **начинается с дефиса** (`-`), чтобы `grep` не принял его за флаг

**Пример:** Найти строки, содержащие «error» или «warning».
```bash
grep -e "error" -e "warning" log.txt
```

**Пример**: Найти точные вхождения **слова** `-std=c11` (флаг `-w` требует, чтобы слово совпало целиком, а не было частью другого слова):
```file
-std=c11
-std=c11345
-std
```

```bash
cat file.txt | grep -w -e "-std=c11"

-std=c11
```


### `-i` (Игнорировать регистр)

Флаг `--ignore-case` делает поиск нечувствительным к регистру символов. Шаблон `Error` будет соответствовать и `error`, и `ERROR`, и `eRrOr`.

```file
apple
Apple
applepen other text
banana brain
app and other text
```

```bash
cat tests/data/file.txt | grep -i "apple"

apple
Apple
applepen other text
```

### `-v` (Инвертировать поиск)

Флаг `--invert-match` меняет логику на противоположную: `grep` выводит **только те строки, которые НЕ соответствуют** шаблону. Это полезно для фильтрации нежелательных строк (например, комментариев).[](https://docs.oracle.com/cd/E36784_01/html/E36870/grep-1g.html#1)

```file.txt
apple
Apple
# comment
this is not comment
# comment 2
```

```bash
cat tests/data/file.txt | grep -v "#"

apple
Apple
this is not comment
```

### `-l` (Только имена совпадающих файлов)

Флаг `--files-with-matches` подавляет вывод самих строк и вместо этого печатает **только имена файлов**, в которых было найдено хотя бы одно совпадение. Поиск в каждом файле прекращается после первого найденного совпадения для экономии времени.[](https://docs.oracle.com/cd/E36784_01/html/E36870/grep-1g.html#1)

**Пример:** Найти все `.txt` файлы в текущей директории, содержащие слово n`apple`.

```bash
grep -l "apple" tests/data/*.txt

tests/data/file1.txt
```

### `-n` (Номер строки)

Флаг `--line-number` добавляет к каждой выводимой строке **её порядковый номер** в файле. Это очень удобно для навигации по коду или логам

```file1.txt
apple
Apple
milk
honey
```

```file2.txt
cinnabon
sugar
coffee
milk
```

```bash
grep "milk" -n tests/data/file1.txt tests/data/file2.txt

tests/data/file1.txt:3:milk
tests/data/file2.txt:4:milk
```

### `-h` (Не выводить имена файлов)

Флаг `--no-filename` подавляет вывод имён файлов перед совпавшими строками. Это поведение по умолчанию, если `grep` ищет только в одном файле. Однако при поиске в нескольких файлах `grep` по умолчанию добавляет имя файла к каждой строке, и `-h` отключает это, делая вывод более чистым

*(тестовые данные из примера выше)*

Без флага `-h` (обычное поведение):
```bash
grep "milk" tests/data/file1.txt tests/data/file2.txt

tests/data/file1.txt:milk
tests/data/file2.txt:milk
```

С флагом:
```bash
grep "milk" -h tests/data/file1.txt tests/data/file2.txt

milk
milk
```

### `-s` (Подавлять сообщения об ошибках)

Флаг `--no-messages` подавляет вывод сообщений об ошибках, связанных с **несуществующими или нечитаемыми файлами**. Это может быть полезно в скриптах, где отсутствие файла — ожидаемая ситуация.[](https://docs.oracle.com/cd/E36784_01/html/E36870/grep-1g.html#1)

**Пример:** Попытаться найти «data» в файле, который может не существовать, не выводя ошибку, если его нет.

Без флага `-s` появится сообщение об ошибке:
```bash
grep "data" possibly_missing_file.txt
grep: possibly_missing_file.txt: No such file or directory
```

С флагом:
```bash
grep -s "data" possibly_missing_file.txt
```

### `-f file` (Получать шаблоны из файла)

Флаг `--file=FILE` указывает `grep` прочитать шаблоны для поиска из указанного файла, по одному шаблону на строку. Это эквивалентно использованию нескольких флагов `-e`, но гораздо удобнее при большом количестве шаблонов.[](https://docs.oracle.com/cd/E36784_01/html/E36870/grep-1g.html#1)

**Пример:** Искать в `access.log` любые строки, содержащие IP-адреса из списка `blocked_ips.txt`.

```blocked_ips.txt
192.168.1.34
192.168.1.35
192.168.1.36
```

```access.log
192.168.1.1
192.168.1.2
192.168.1.20
192.168.1.34
192.168.1.35
192.168.1.41
```

```bash
grep -f tests/data/blocked_ips.txt tests/data/access.log

192.168.1.34
192.168.1.35
```

### `-o` (Только совпадающая часть)

Флаг `--only-matching` выводит **только ту часть строки, которая совпала с шаблоном**, а не всю строку целиком. Каждое совпадение выводится на новой строке. Это полезно для извлечения данных (например, чисел или email-адресов) из текста.
