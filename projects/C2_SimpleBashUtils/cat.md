# Флаги команды `cat`

| Короткий флаг | Длинный флаг (GNU) | Описание |
|:---:|:---|:---|
| `-A` | `--show-all` | Эквивалент `-vET`. Показывает все непечатаемые символы. |
| `-b` | `--number-nonblank` | Нумерует только непустые строки, начиная с 1. Перекрывает действие `-n`. |
| `-e` | Нет | Эквивалент `-vE`. Показывает конец строки (`$`) и непечатаемые символы. |
| `-E` | `--show-ends` | Отображает `$` в конце каждой строки. |
| `-n` | `--number` | Нумерует все строки вывода, начиная с 1. |
| `-s` | `--squeeze-blank` | Сжимает несколько подряд идущих пустых строк в одну. |
| `-t` | Нет | Эквивалент `-vT`. Показывает табуляцию (`^I`) и непечатаемые символы. |
| `-T` | `--show-tabs` | Отображает символы табуляции как `^I`. |
| `-u` | Нет | Игнорируется. Оставлен для совместимости с POSIX. |
| `-v` | `--show-nonprinting` | Отображает непечатаемые символы (кроме LFD и TAB) в нотации `^` и `M-`. |
| Нет | `--help` | Показывает справку и выходит. |
| Нет | `--version` | Показывает информацию о версии и выходит. |


### Семантика флагов на уровне программы

-A  show_nonprinting + show_ends + show_tabs
-b  number_nonblank
-e  show_nonprinting + show_ends
-E  show_ends
-n  number_all
-s  squeeze_blank
-t  show_nonprinting + show_tabs
-T  show_tabs
-v  show_nonprinting
