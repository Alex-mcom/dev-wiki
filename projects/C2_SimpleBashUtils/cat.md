# Флаги команды `cat`

| Короткий флаг | Длинный флаг (GNU)   | Описание                                                                 | Есть в Busybox? |
| :-----------: | :------------------- | :----------------------------------------------------------------------- | :-------------- |
|     `-A`      | `--show-all`         | Эквивалент `-vET`. Показывает все непечатаемые символы.                  | Да              |
|     `-b`      | `--number-nonblank`  | Нумерует только непустые строки, начиная с 1. Перекрывает действие `-n`. | Да              |
|     `-e`      | Нет                  | Эквивалент `-vE`. Показывает конец строки (`$`) и непечатаемые символы.  | Да              |
|     `-E`      | `--show-ends`        | Отображает `$` в конце каждой строки. для `\r\n` отображает `^M$`        | Нет             |
|     `-n`      | `--number`           | Нумерует все строки вывода, начиная с 1.                                 | Да              |
|     `-s`      | `--squeeze-blank`    | Сжимает несколько подряд идущих пустых строк в одну.                     | Нет             |
|     `-t`      | Нет                  | Эквивалент `-vT`. Показывает табуляцию (`^I`) и непечатаемые символы.    | Да              |
|     `-T`      | `--show-tabs`        | Отображает символы табуляции как `^I`.                                   | Нет             |
|     `-u`      | Нет                  | Игнорируется. Оставлен для совместимости с POSIX.                        | Нет             |
|     `-v`      | `--show-nonprinting` | Отображает непечатаемые символы (кроме LFD и TAB) в нотации `^` и `M-`.  | Да              |
|      Нет      | `--help`             | Показывает справку и выходит.                                            |                 |
|      Нет      | `--version`          | Показывает информацию о версии и выходит.                                |                 |


### Семантика флагов на уровне программы

-A  show_nonprinting + show_ends + show_tabs
-b  number_nonblank
-e  show_nonprinting + show_ends
-E  show_ends
-n  number_all
-s  squeeze_blank
-t  show_nonprinting + show_tabs
-T  show_tabs
-v  show_nonprinting
