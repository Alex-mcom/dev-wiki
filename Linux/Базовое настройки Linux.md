## Обновление ОС

В Ubuntu пакеты ставятся и обновляются через менеджер пакетов `apt`. Обновление выполняется в два шага: сначала обновляется индекс пакетов, затем сами пакеты.

```bash
sudo apt update          # обновить список доступных версий пакетов
sudo apt upgrade -y      # установить новые версии уже установленных пакетов
```

- `apt update` ничего не устанавливает, а только скачивает из репозиториев актуальную информацию о пакетах.
- `apt upgrade` устанавливает обновления, не удаляя установленные пакеты.
- `apt full-upgrade` (аналог `dist-upgrade`) дополнительно может удалять и добавлять пакеты, если этого требуют зависимости. Нужен, если `upgrade` оставляет часть пакетов "held back".
- Ключ `-y` автоматически отвечает «да» на запросы подтверждения.

Если обновилось ядро, нужна перезагрузка:

```bash
sudo reboot
```
