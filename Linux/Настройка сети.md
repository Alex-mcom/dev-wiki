## Имя машины

Имя хоста (hostname) — название компьютера в сети. Задаётся командой `hostnamectl`, изменения сохраняются в `/etc/hostname`.

```bash
sudo hostnamectl set-hostname user-1   # задать имя
hostnamectl                            # проверить
```

>Изменения вступают в силу сразу. Чтобы приглашение в терминале обновилось, нужно перелогиниться.

Имя хоста не привязано к пользователю, потому что это свойство машины, а не учётной записи. Пользователь — это один из аккаунтов внутри системы, а hostname — название самой системы. Поэтому имя хранится в `/etc/hostname`, и оно одно на всех. Поэтому в приглашении `user@user-1:~$` две части берутся из разных мест: до `@` — текущий пользователь сессии, после — имя машины.

Если зайти на машину под разными пользователями, имя хоста будет одним и тем же:

```bash
ssh alice@192.168.1.10   # приглашение: alice@user-1
ssh bob@192.168.1.10     # приглашение: bob@user-1
```

Подключение идёт к **машине**, а пользователь только выбирает, под какой учёткой в ней работать. Аналогия: у дома один адрес, а жильцов в нём может быть много.

Не стоит и считать hostname «адресом» в сети. Для сети важен IP, а hostname — удобная метка, которую другие компьютеры могут преобразовывать в IP через DNS, `/etc/hosts` или mDNS. Он не обязан быть уникальным в мире, поэтому две машины с одинаковым именем в одной сети вызовут путаницу.
