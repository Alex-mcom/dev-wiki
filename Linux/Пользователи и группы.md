## Пользователи

Linux многопользовательская система: каждый процесс и каждый файл принадлежат
конкретному пользователю. Это основа безопасности и разграничения прав.

Типы пользователей по UID:

- `0` — root, суперпользователь
- `1-999` — системные, под ними работают службы (`sshd`, `syslog`, `www-data`)
- `1000+` — обычные пользователи, то есть реальные люди

У системных пользователей оболочка `/usr/sbin/nologin` или `/bin/false`,
войти под ними нельзя. Если взломают службу, атакующий получит права только
её пользователя, а не всей системы.


### Файл /etc/passwd

Одна строка — один пользователь, поля разделены двоеточием:

```bash
patrik:x:1001:1001:Patrik Sanderson:/home/patrik:/bin/bash
```

1. Имя пользователя
2. `x` — пароль хранится в `/etc/shadow` (в виде хеша)
3. UID
4. GID основной группы
5. Комментарий (полное имя)
6. Домашний каталог
7. Оболочка входа

Файл читают все, а хеши паролей лежат в `/etc/shadow`, куда доступ есть только у root.


### Создание пользователя

```bash
sudo adduser patrik                        # интерактивно, рекомендуется

sudo useradd -m -s /bin/bash -G adm patrik # низкоуровневая утилита
sudo passwd patrik                         # пароль для useradd
```

- `adduser` — дружелюбная обёртка (Debian/Ubuntu): создаёт домашний каталог,
  спрашивает пароль и данные
- `useradd` — базовая утилита: без `-m` не создаёт домашний каталог,
  без `-s` оболочка может оказаться `/bin/sh`, пароль нужно задавать отдельно

Удаление: `sudo userdel -r patrik` (`-r` удаляет и домашний каталог).


## Группы

Группа объединяет пользователей, чтобы выдавать права сразу всем, а не по одному.
У каждого файла есть владелец, группа-владелец и права `rwx` для трёх категорий: владелец, группа, остальные.

Виды групп:

- **основная** — одна на пользователя, указана в `/etc/passwd`;
  новые файлы создаются с ней
- **дополнительные** — все остальные группы, в которые добавлен пользователь

Частые группы в Ubuntu:

- `sudo` — право использовать sudo
- `adm` — чтение системных логов в `/var/log`
- `users` — общая группа обычных пользователей
- `cdrom`, `dip`, `plugdev` — доступ к приводам, сетевым соединениям, сменным устройствам
- `lxd` — управление контейнерами LXD

## Управление группами

```bash
groups              # группы текущего пользователя
groups patrik       # группы указанного пользователя
id patrik           # то же, с числовыми id
getent group adm    # кто входит в группу adm
cat /etc/group      # все группы

sudo groupadd devs               # создать группу

sudo usermod -aG adm patrik      # добавить пользователя в группу
sudo adduser patrik adm          # добавить patrik в adm

sudo gpasswd -d patrik adm       # убрать пользователя из группы
```

Флаг `-a` в `usermod -aG` обязателен. Без него `-G` заменит все
дополнительные группы пользователя на указанную.

Изменения групп применяются после нового входа пользователя в систему.
